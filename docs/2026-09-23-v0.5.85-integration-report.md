## Kontrak readiness final

- `/api/health` tetap liveness publik dan tidak bergantung pada readiness DB.
- `/api/ready` mengembalikan 200 hanya jika adapter DB bekerja dan `_meta.schemaVersion` sama dengan `SCHEMA_VERSION`.
- `/api/ready` hanya dapat diakses dari loopback/internal trust path.
- Remote GET, remote OPTIONS, spoofed forwarding headers, forged peer token, master gateway, serta public proxy menerima 404.
- Cursor migrasi memakai `_meta.migrationVersion`.
- `_meta.schemaVersion` hanya menjadi marker readiness.
- Marker lama dihapus sebelum migrasi/schema sync.
- Marker baru dipublikasikan hanya setelah migrasi dan import selesai.
- Kegagalan PostgreSQL `ADD COLUMN` dipropagasikan. Proses tetap unready.
- `getAdapter()` dapat pulih setelah inisialisasi DB sebelumnya gagal.
